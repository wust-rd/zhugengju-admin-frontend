## 3. 新增「片区城市设计」区块（★ 契约变更，位于片区功能策划之后）

tab 多设计填报，六类固定枚举、**同一片区内 type 不可重复**（前端已约束）：
人居环境 / 产业发展 / 历史文化保护 / 基础设施建设 / 生态环境整治 / 交通影响评价。
每个类别填：主要内容（≤300 字）+ 设计图片（jpg/png，多张，MinIO 文件对象数组）。

| 字段 | 方向 | 说明 |
|------|------|------|
| `cityDesigns` | **新增**（保存/回显） | 数组 `[{type, content, images}]`；images 为文件对象数组 |

保存 JSON 示例：

```json
"cityDesigns": [
  {
    "type": "人居环境",
    "content": "重点改造 3 个老旧小区人居环境……",
    "images": [{"name": "a.jpg", "url": "http://…", "objectKey": "esp/scheme-fill/…", "size": 10240}]
  }
]
```

后端 TODO（存储方案二选一，推荐 A）：
- A. 单列 JSON：`ALTER TABLE ESP_MAP_AREA ADD city_designs CLOB;` 整组 JSON 直接落列
  （图片直链已在文件对象里，无需进 ESP_FILE_URL）；回显原样返回；
- B. 若城市设计图片需要走文件位统一管理，可拆 `city_design` 明细表 + 文件位
  （field_code = `city_design_{类别序}`），前端契约不变。
- `detailRow` / `emptyScheme` 增加 `cityDesigns`（空为 `[]`）键。
